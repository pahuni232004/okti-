📊 Google Sheets Integration Test

📋 Setup Instructions

Before testing, make sure you have:

  1. Created a Google Sheets file named "Okti Foundation Donations"
  2. Set up Google Apps Script with the provided code
  3. Deployed the script as a web app with "Anyone" access
  4. Added GOOGLE_APPS_SCRIPT_URL to Netlify environment variables
  5. Redeployed the site

1. Test Google Sheets Function

This tests if the Google Sheets integration is working.

2. Test with Sample Donation Data

This simulates a real donation and saves it to your Google Sheets.

3. Check Configuration

This checks if the Google Sheets configuration is properly set up.

📊 Expected Results

If everything is working correctly, you should see in your Google Sheets:

Sample data that will be added:
• Date & Time: Current timestamp
• Donor Name: Test Donor
• Email: test@example.com
• Phone: +91 98765 43210
• Donation Amount: ₹1,000
• Donation Type: one-time
• Status: Completed

🔧 Troubleshooting

If you see errors:

  • "Google Sheets configuration error" → Check environment variable
  • "Failed to save donation details" → Check Apps Script deployment
  • "Network error" → Check Apps Script URL
